# Task Manager

Uma aplicação CLI desenvolvida em Go para gerenciamento de tarefas.

## Objetivos

Este projeto foi desenvolvido com fins didáticos e demonstra boas práticas de desenvolvimento em Go.

Ao longo da evolução do projeto serão abordados:

- organização de projetos
- SQLite
- database/sql
- interfaces
- repository pattern
- services
- CLI
- tratamento de erros
- boas práticas idiomáticas
